# เทียบวิธีกรอกกระสอบทราย 3 แบบ

อนิเมชั่น 3 มิติ (three.js ไฟล์เดียว `index.html`) เทียบ **กระสอบมีปีก (GGS)**, **กระสอบบังเกอร์** และ **Flex MSE** ทั้งขนาด ขั้นตอนการกรอก และการขน (รถเข็น / ขึ้นสโลป)

เปิดดู: https://korakotkkrt-dev.github.io/bag-filling-compare/

## แท็บในหน้าเว็บ
ขนาด · กรอก: มีปีก · กรอก: บังเกอร์ · กรอก: Flex MSE · เทียบ 3 แบบ · ขนรถเข็น · ขนขึ้นสโลป
(กดเล่น/หยุด ลากแถบเวลา เลือกขั้นที่ 1–4 และหมุนมุมมองได้)

## ข้อมูลที่ใช้
- กระสอบมีปีก: แบบ 690044 CE แผ่น 8/8 — ผ้า 1.50 x 0.75 ม. ส่วนบรรจุ 0.75 x 0.45 ม. ปากกรวยกว้างบน คอแคบ ~0.19 ม.; ทรายต่อใบ ~55 ลิตร (จากไฟล์คำนวณของผู้ใช้)
- กระสอบบังเกอร์: ป้ายสินค้า 35 x 75 ซม. เติมประมาณ 2/3 (~17 ลิตร)
- Flex MSE: คลิปทางการ (Bag Filling with Jigs / with Machine) — ขั้นต่ำ 32 ลิตร ใบละ 32 กก. (ดินผสม) ขนาดหลังกรอก ~0.66–0.71 x 0.30 x 0.14 ม.
- ความหนาแน่นทราย 1,500–1,700 กก./ม³ (ใช้ 1,600 เป็นค่ากลาง)

## ข้อจำกัด
ภาพจำลองเพื่อเทียบขั้นตอน **ไม่ใช่เวลาจริงหน้างาน** ขนาดหลังกรอกและน้ำหนักเป็นค่าคำนวณ/ประมาณ ยังไม่ได้ชั่งหรือวัดของจริง ท่าทางคนและเครื่องมือเป็นแบบง่าย

## ไฟล์
- `index.html` — ตัวแสดงผลสำเร็จรูป (ฝัง three.js ไว้แล้ว)
- `app.js`, `template.html`, `libs.js`, `build.py` — ซอร์ส (`python build.py` สร้าง `index.html`)
- `sketchup/` — โมเดล SketchUp (`bag_compare_3types.skp` 23 ฉาก) และภาพสรุป
